# nhl-analytics
End-to-end NHL analytics pipeline using Python, pandas, and Tableau. Analyzes 20 years of player and goalie performance data.
# NHL Analytics Pipeline

## Overview
End-to-end data analytics pipeline analyzing 20 years of NHL player and goalie performance data (2000-2019).

## Tools Used
- Python (pandas)
- Tableau Public

## Analysis
- Top 10 NHL scorers by total goals and assists
- Top 10 goalies by save percentage (minimum 70 games played)
- NHL player nationality breakdown
